- (event) Create intent; sources: final PRD + brief (both in planning-artifacts). Stakes: hobby/solo
- (event) Fast path; user delegated all visual and behavioral decisions ('make good decisions'), no questions. Decisions below are delegated, not elicited; creative tools and mocks skipped
- (decision) Visual posture: dark, high-contrast 'hardware device / tuner' look — near-black surface, off-white beats, one amber accent reserved for beat 1. Reason: readable from the corner of the eye, less glare on a practice stand
- (decision) Dark theme only; no light mode or system-theme following in v1. Reason: one look, less to build
- (decision) No UI component library; plain Angular components. Reason: four inputs and one button do not justify Material
- (decision) Typography: system-ui stack with tabular numerals, no bundled web fonts. Reason: offline Electron app, numbers must not jitter in width
- (decision) One window, two states: Idle (settings form + Start) and Playing (settings collapse to a read-only strip; beat display takes the rest). Reason: PRD locks settings during a Session
- (decision) Beat display: four large blocks in a row, current one lit; beat 1 lit in amber, others off-white; big BPM number above, countdown line below. Scales with window (vmin)
- (decision) Resolves PRD FR-8 assumption: in Hold, countdown line reads 'Holding at {ceiling-reached tempo} BPM'
- (decision) Resolves PRD FR-2 assumption: Start disabled for invalid Settings, with one inline hint line naming the problem
- (decision) No animation or transitions on beats — highlight switches instantly, in sync with the click. Reason: transitions blur timing
- (decision) Palette contrast checked: text 16.4:1, muted 7.3:1, accent 10.5:1, border 4.0:1 on surface; beat-off intentionally low (1.4:1, decorative)
- (assumption) Launch defaults 60/120/5/4; Enter starts, Escape stops (additive to PRD FR-4); audio-unavailable shown as hint line
- (decision) Beat 1 marked by colour plus permanent amber outline (not colour alone)
- (decision) Flash threshold >3/s above 180 BPM accepted for personal tool; NOTE FOR UX to revisit if shared
- (event) Spines written; PRD coverage check: FR-1..FR-8 all have a surface/state, both PRD assumptions resolved. Reviewer gate and key-screen mocks skipped (user asked for no questions, fast path). Polish done inline
- (event) spines finalized
